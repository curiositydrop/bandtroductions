# BANDtroductions homepage design preview

Standalone visual prototype. Open `index.html` with a static server. Only this new directory is changed; the existing root homepage and all production modules remain untouched.

## Scope
- Desktop reference composition retained on phones: wide split hero, four-column discovery and role cards, three community teasers, spotlight, upgrade banner, and radio mockup.
- Live logo copied unchanged from `IMG_9367.png`; site teal #25c7c1, charcoal #090a0a.
- Fictional sample posts and spotlight. Generated musicians are not representations of real member bands.
- No Firebase, analytics, payments, service worker, external fonts, live content, or audio. CSP disallows connections, media, frames, and form submission. Buttons only explain that the design is not connected; anchor links move within this preview.
- Small mobile typography deliberately preserves Mike's desktop-style layout preference. Pinch zoom remains enabled. Revisit readability together during design review.

## Images
Created with the built-in image-generation tool. `hero.webp`: teal/amber concert singer at right, dark space at left. `scene-cards.webp`: eight-scene photographic sheet arranged four columns by two rows, displayed as individual CSS image windows. `spotlight.webp`: fictional rock band at right with dark space at left. Actual live logo is not generated.

Move existing dashboard to a Social address, preserve old post deep links, then connect approved homepage sections. Continuous radio is a separate project. Do not merge this preview as a production replacement without explicit approval.
